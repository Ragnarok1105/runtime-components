# Runtime Components

My configuration files for Bash, Zsh, Vim, GDB, and Git.

## Files
- .bashrc: Bash shell settings and aliases
- .zshrc: Zsh shell settings and plugins
- .vimrc: Vim editor settings
- .gdbinit: GDB debugger settings
- .gitconfig: Shared Git settings
- install.sh: Installs the configuration files

## Installation
Preview changes with: ./install.sh --dry-run
Install with: ./install.sh

The Git configuration keeps my personal name and email separate.
